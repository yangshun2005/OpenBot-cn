# 内置品牌标识

来自 [`@lobehub/icons-static-svg`](https://github.com/lobehub/lobe-icons)，MIT 许可，采用内置方式而非动态获取，因为设置窗口在绘制时无法保证网络可用。

已重命名为它们所属的 harness 或 provider id，这样每一行都能通过自己的 id 找到对应标识，无需维护第二份映射关系。

每个标识都是其所有者的商标，仅用于在选择器中标识该产品，别无他用。
**此处没有任何虚构内容。** Agno、AG2 和 Langroid 在任何维护中的图标集中都没有标识，因此它们的行仅显示名称。如果我们自行绘制一个字母组合标识，会被误认为是厂商自己的标识，而这正是商标持有人真正反对的事情。

每一行都会显示其名称，无论是否有标识。标识位于名称旁边，绝不替代名称。
