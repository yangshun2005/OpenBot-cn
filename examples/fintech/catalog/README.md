# 供复制的同事

此目录中的内容不会被加载。每个文件声明一个同事，格式与 `../agents/` 读取的格式一致：将文件复制到 `../agents/` 中，下次启动时便会注册它。它们过去默认加载，这会在每次新部署时一次性将十几个 Bot 推到前台。

每个同事一个文件的意义在于，同事成为你可以处理的东西：复制一个进来，删除一个你不想要的，把一个发送给别人。这里的任何内容都不是授权。同事指定技能，技能指定工具，而它实际可以调用的内容取决于管理员授予它的权限，因此复制到 `../agents/` 中的文件只添加了一条指令，而不添加任何能力。

这十个同事旨在为你提供一个起点，而非覆盖一个矩阵，并且它们刻意彼此不同：财务、会议、发布、支持、入职、研究、招聘、可靠性、采购和产品反馈。值得复制的部分是 `role_description` 的结构：它说明了工作是什么、同事不得做什么，以及当它找不到某些内容时该说什么。一行描述只会让你得到一个回答含糊的同事。

更多同事，位于此仓库之外，且不会被你的克隆继承：
